Dieses Glossar enthält die massgeblichen deutschen Ubersetzungen fur die in Akeeba Data Compliance verwendeten Fachbegriffe. Die Ubersetzungen der datenschutzrechtlichen Begriffe basieren auf der Datenschutz-Grundverordnung (DSGVO) in ihrer amtlichen deutschen Fassung (Verordnung (EU) 2016/679). Technische Begriffe ohne amtliche DSGVO-Entsprechung folgen dem allgemeinen deutschen IT-Sprachgebrauch. Ziel ist eine konsistente, rechtssichere und fur deutschsprachige Benutzer verstandliche Ubersetzung der Benutzeroberflache und der Dokumentation der Erweiterung.

| English Term | German (Germany) Translation | Notes |
|---|---|---|
| Data Compliance | Datenschutz-Compliance | Eingeburgerter Begriff fur die Einhaltung datenschutzrechtlicher Vorschriften; "Compliance" ist im deutschen Rechts- und Unternehmenskontext etabliert. Alternativ: Datenschutzkonformitat. |
| GDPR / General Data Protection Regulation | DSGVO / Datenschutz-Grundverordnung | Amtliche deutsche Bezeichnung gemas Verordnung (EU) 2016/679. Die Abkurzung DSGVO ist im deutschsprachigen Raum allgemein gebrauchlich. |
| Personal data | Personenbezogene Daten | Amtlicher DSGVO-Begriff (Art. 4 Nr. 1 DSGVO). Stets im Plural verwenden. |
| Personally identifiable information (PII) | Personenbezogene Daten | Im DSGVO-Kontext als "personenbezogene Daten" ubersetzt; der englische Begriff PII hat im deutschen Recht keine eigenstandige Entsprechung. |
| Consent / Consent to data processing | Einwilligung / Einwilligung in die Datenverarbeitung | Amtlicher DSGVO-Begriff (Art. 4 Nr. 11, Art. 7 DSGVO). Nicht: "Zustimmung" oder "Genehmigung". |
| Right to be forgotten | Recht auf Loschung / Recht auf Vergessenwerden | Amtlicher DSGVO-Begriff (Art. 17 DSGVO, Uberschrift: "Recht auf Loschung ('Recht auf Vergessenwerden')"). Beide Formulierungen sind zulassig; in der Benutzeroberflache bevorzugt: "Recht auf Loschung". |
| Data portability right | Recht auf Datenuberragbarkeit | Amtlicher DSGVO-Begriff (Art. 20 DSGVO). Auch: "Datenubertragbarkeitsrecht". |
| User account | Benutzerkonto | Standardbegriff in der deutschen Software-Lokalisierung. Alternativ: "Nutzerkonto". |
| User profile | Benutzerprofil | Standardbegriff in der deutschen Software-Lokalisierung. |
| Delete / Deletion | Loschen / Loschung | Amtlicher DSGVO-Begriff fur die Beseitigung personenbezogener Daten (Art. 17 DSGVO). |
| Wipe / Permanent deletion | Unwiederrufliches Loschen / Endgultiges Loschen | Bezeichnet die vollstandige, nicht wiederherstellbare Loschung aller personenbezogenen Daten eines Benutzerkontos. In der Benutzeroberflache: "Konto endgultig loschen". Nicht: "Wipe" als Lehnwort. |
| Export / Data export | Exportieren / Datenexport | Allgemeiner IT-Begriff; im DSGVO-Kontext im Zusammenhang mit dem Recht auf Datenuberragbarkeit (Art. 20 DSGVO). |
| Audit trail / Audit log | Protokoll / Prufpfad / Revisionsprotokoll | "Prufpfad" ist die gebrauchlichste Ubersetzung von "audit trail" in deutschen IT-Sicherheits- und Compliance-Kontexten. "Revisionsprotokoll" ist ebenfalls korrekt. In der Benutzeroberflache kann kurz "Protokoll" verwendet werden. |
| Administrator | Administrator | Im Joomla-Kontext unverandert ubernommen; die deutsche Entsprechung "Verwalter" ist unublich. |
| Super User | Super-Benutzer | Joomla-spezifische Rolle; Bindestrich gemas deutschem Rechtschreibgebrauch. |
| Account lifecycle / Lifecycle policy | Kontolebenszyklus / Lebenszyklusrichtlinie | "Lebenszyklus" ist der standardisierte deutsche Begriff fur "lifecycle" in IT- und Datenschutzkontexten. |
| Inactive account | Inaktives Konto | Standardbegriff; bezeichnet ein Benutzerkonto, das seit einem definierten Zeitraum nicht mehr genutzt wurde. |
| Privacy Statement / Privacy Policy | Datenschutzerklarung | Amtlich gebrauchlicher Begriff im deutschen Datenschutzrecht (gemas Art. 13, 14 DSGVO). Nicht: "Privatspharenrichtlinie" oder "Privatsphare-Erklarung". |
| Data rights | Betroffenenrechte | Amtlicher DSGVO-Begriff fur die Rechte der betroffenen Personen (Kapitel III DSGVO, Art. 12-23). Auch: "Datenschutzrechte". |
| Pseudonymise / Pseudonymisation | Pseudonymisieren / Pseudonymisierung | Amtlicher DSGVO-Begriff (Art. 4 Nr. 5, Art. 25 DSGVO). |
| Anonymise / Anonymisation | Anonymisieren / Anonymisierung | Im DSGVO-Kontext verwendeter Begriff; Erwagunsgurnd 26 DSGVO. Anonymisierte Daten fallen nicht mehr unter den Anwendungsbereich der DSGVO. |
| Plugin | Plugin | Im Joomla-Kontext unverandert; allgemein etablierter Fachbegriff in der deutschen IT-Sprache. Kein Artikel-Genus-Problem: "das Plugin". |
| Component | Komponente | Standardubersetzung fur Joomla-Komponenten in der deutschen Joomla-Lokalisierung. |
| Blocked account | Gesperrtes Konto | Bezeichnet ein Benutzerkonto, das durch einen Administrator gesperrt wurde. |
| Dashboard | Dashboard | Im deutschen IT-Sprachgebrauch allgemein etablierter Begriff. Alternativ: "Ubersichtsseite", jedoch ist "Dashboard" in Joomla-Lokalisierungen ublich. |
| Configuration | Konfiguration | Standardubersetzung in der deutschen Software-Lokalisierung. |
| Email template | E-Mail-Vorlage | Standardubersetzung; gemas deutschem Rechtschreibgebrauch mit Bindestrich: "E-Mail-Vorlage". |
| Notification | Benachrichtigung | Standardubersetzung in der deutschen Software-Lokalisierung. |
| Consent trail | Einwilligungsprotokoll | Bezeichnet das Prufpfad-Protokoll, das Zeitpunkt und IP-Adresse jeder erteilten oder widerrufenen Einwilligung eines Benutzers aufzeichnet. |
| Export trail | Exportprotokoll | Bezeichnet das Prufpfad-Protokoll der durchgefuhrten Datenexporte. |
| Wipe trail | Loschprotokoll | Bezeichnet das Prufpfad-Protokoll der durchgefuhrten Kontloschungen. |
| User trail / Profile change log | Anderungsprotokoll / Benutzerprofil-Anderungsprotokoll | Bezeichnet das Prufpfad-Protokoll der Anderungen an Benutzerprofilen. |
| Profile changes | Profilanderungen | Bezeichnung fur die am Benutzerprofil vorgenommenen Anderungen, wie sie im Anderungsprotokoll erfasst werden. |
| Profile deletion | Profilloschung | Bezeichnung fur die vollstandige Loschung eines Benutzerprofils. |
| Lifecycle expiry / Expired profile | Lebenszyklusablauf / Abgelaufenes Profil | Bezeichnet ein Benutzerprofil, dessen definierte Aufbewahrungsfrist abgelaufen ist und das automatisch geloscht werden soll (Datensparsamkeit, Art. 5 Abs. 1 lit. e DSGVO). |
| Data minimisation | Datensparsamkeit / Datenminimierung | Amtlicher DSGVO-Begriff (Art. 5 Abs. 1 lit. c DSGVO: "Datenminimierung"). Im allgemeinen Datenschutzdiskurs auch: "Datensparsamkeit". |
| Dry run | Testlauf / Probelauf | Bezeichnet die Ausfuhrung eines Prozesses ohne tatsachliche Anderungen (nur Simulation). Nicht: "Dry Run" als Anglizismus. |
| Access Key (AWS S3) | Zugriffsschlussel | Deutsche Ubersetzung des AWS-Begriffs "Access Key"; bezeichnet den offentlichen Teil des AWS-Authentifizierungsschlusselpaares. |
| Secret Key (AWS S3) | Geheimer Schlussel | Deutsche Ubersetzung des AWS-Begriffs "Secret Key"; bezeichnet den privaten Teil des AWS-Authentifizierungsschlusselpaares. |
| Bucket (AWS S3 storage bucket) | Bucket | Der englische Begriff "Bucket" ist der offizielle, auch in der deutschen AWS-Dokumentation verwendete Begriff fur einen Amazon-S3-Speicherbereich. Keine deutsche Ubersetzung verwenden. |
| Storage class | Speicherklasse | Ubersetzung des AWS-Begriffs "Storage Class" gemas der deutschen AWS-Dokumentation; bezeichnet die Redundanz- und Verfugbarkeitsstufe eines S3-Objekts. |
| Signature method | Signaturmethode | Bezeichnet das Verfahren zur Authentifizierung von API-Anfragen bei Amazon S3 (v2 / v4). |
| Data processing | Datenverarbeitung | Amtlicher DSGVO-Begriff (Art. 4 Nr. 2 DSGVO). |
| Controller (data controller) | Verantwortlicher | Amtlicher DSGVO-Begriff (Art. 4 Nr. 7 DSGVO). |
| Data subject | Betroffene Person | Amtlicher DSGVO-Begriff (Art. 4 Nr. 1 DSGVO). |
| Revoke consent | Einwilligung widerrufen | Amtlicher DSGVO-Begriff (Art. 7 Abs. 3 DSGVO: "Die betroffene Person hat das Recht, ihre Einwilligung jederzeit zu widerrufen."). |
| Right of access | Auskunftsrecht | Amtlicher DSGVO-Begriff (Art. 15 DSGVO). |
| Right to rectification | Recht auf Berichtigung | Amtlicher DSGVO-Begriff (Art. 16 DSGVO). |
| Right to restriction of processing | Recht auf Einschrankung der Verarbeitung | Amtlicher DSGVO-Begriff (Art. 18 DSGVO). |
| Captive page / Consent gate | Einwilligungsseite / Pflichtseite | Bezeichnet die Seite, die Benutzer zur Abgabe ihrer Einwilligung zwingt, bevor sie die Website nutzen konnen. |
| Lifecycle notification | Lebenszyklusbenachrichtigung | Bezeichnet die automatische Benachrichtigung eines Benutzers vor der bevorstehenden automatischen Loschung seines Kontos. |
