Este glossário define as traduções padronizadas para os termos técnicos e jurídicos utilizados na extensão Akeeba Data Compliance para Joomla. As traduções dos termos jurídicos baseiam-se na terminologia oficial do Regulamento (UE) 2016/679 — Regulamento Geral sobre a Proteção de Dados (RGPD) — conforme publicado no Jornal Oficial da União Europeia na versão portuguesa, bem como na Lei n.º 58/2019 de 8 de agosto (lei de execução nacional do RGPD em Portugal). Os termos técnicos de software seguem as convenções estabelecidas na localização portuguesa do Joomla e dos produtos Microsoft/AWS, assegurando coerência com as expetativas dos utilizadores portugueses.

| English Term | Portuguese (Portugal) Translation | Notes |
|---|---|---|
| Data Compliance | Conformidade com a Proteção de Dados | Designação geral do produto/componente. Alternativa aceitável: "Conformidade de Dados". |
| GDPR | RGPD | Acrónimo oficial em português: Regulamento Geral sobre a Proteção de Dados. Nunca usar "GDPR" em texto em português. |
| General Data Protection Regulation | Regulamento Geral sobre a Proteção de Dados | Designação oficial do Regulamento (UE) 2016/679 conforme publicado no Jornal Oficial da UE em português. |
| Personal data | Dados pessoais | Termo definido no Artigo 4.º, n.º 1, do RGPD: "qualquer informação relativa a uma pessoa singular identificada ou identificável". |
| Personally identifiable information (PII) | Informação pessoalmente identificável | Termo de uso corrente em contextos técnicos e de segurança informática; em contexto jurídico-RGPD preferir "dados pessoais". |
| Consent | Consentimento | Artigo 4.º, n.º 11, do RGPD: "manifestação de vontade, livre, específica, informada e explícita". |
| Consent to data processing | Consentimento para o tratamento de dados | Formulação completa conforme o Artigo 6.º, n.º 1, alínea a), do RGPD. |
| Right to be forgotten | Direito ao apagamento ("direito a ser esquecido") | Artigo 17.º do RGPD. A expressão entre parênteses é a designação popular; "direito ao apagamento" é a designação jurídica oficial. |
| Data portability right | Direito à portabilidade dos dados | Artigo 20.º do RGPD. |
| User account | Conta de utilizador | Terminologia padrão do Joomla em português. |
| User profile | Perfil de utilizador | Terminologia padrão do Joomla em português. |
| Delete | Eliminar | Ação genérica de remoção de dados ou registos. |
| Deletion | Eliminação | Substantivo correspondente ao ato de eliminar. |
| Wipe (permanent deletion) | Apagamento (eliminação permanente) | Usado para a eliminação definitiva e irreversível de dados pessoais, conforme previsto no Artigo 17.º do RGPD. Distingue-se da simples eliminação lógica. |
| Export | Exportar / Exportação | Verbo e substantivo, respetivamente, para a extração de dados em ficheiro. |
| Data export | Exportação de dados | Ação de exportar os dados pessoais do utilizador (exercício do direito à portabilidade). |
| Audit trail | Registo de auditoria | Registo cronológico de ações realizadas no sistema para fins de responsabilização e conformidade. Alternativa: "trilho de auditoria" (menos comum em PT-PT). |
| Audit log | Diário de auditoria | Ficheiro ou registo que contém as entradas do registo de auditoria. Pode usar-se "registo de auditoria" de forma intercambiável. |
| Administrator | Administrador | Papel de utilizador com permissões de gestão do site no Joomla. |
| Super User | Super Utilizador | Nível máximo de privilégios no Joomla; manter a maiúscula inicial por ser um papel específico da plataforma. |
| Account lifecycle | Ciclo de vida da conta | Política que determina a criação, manutenção e eliminação automática de contas de utilizador inativas. |
| Lifecycle policy | Política do ciclo de vida | As regras que definem quando uma conta expira e deve ser eliminada. |
| Inactive account | Conta inativa | Conta de utilizador sem atividade de sessão dentro do período definido pela política do ciclo de vida. |
| Privacy Statement | Declaração de Privacidade | Documento informativo dirigido aos titulares dos dados, nos termos dos Artigos 13.º e 14.º do RGPD. Alternativa de uso corrente: "Política de Privacidade". |
| Privacy Policy | Política de Privacidade | Termo de uso comum; juridicamente equivalente a "Declaração de Privacidade". |
| Data rights | Direitos sobre os dados | Direitos dos titulares dos dados previstos nos Capítulos III do RGPD (acesso, retificação, apagamento, portabilidade, etc.). |
| Pseudonymise | Pseudonimizar | Artigo 4.º, n.º 5, do RGPD: "tratamento de dados pessoais de forma que deixem de poder ser atribuídos a um titular de dados específico sem recorrer a informações suplementares". |
| Anonymise | Anonimizar | Tornar os dados pessoais irreversivelmente anónimos, de modo a que o titular não seja identificável. Dados anonimizados deixam de ser abrangidos pelo RGPD. |
| Plugin | Plugin | Termo técnico do Joomla adotado sem tradução no ecossistema em português. Alternativa formal: "extensão de plugin". |
| Component | Componente | Tipo de extensão principal do Joomla, responsável pela funcionalidade central. |
| Blocked account | Conta bloqueada | Conta de utilizador cujo acesso foi suspenso/desativado pelo administrador. |
| Dashboard | Painel de controlo | Página de resumo com indicadores e ações rápidas na interface de administração. |
| Configuration | Configuração | Página e conjunto de parâmetros que controlam o comportamento da extensão. |
| Email template | Modelo de e-mail | Mensagem de e-mail pré-formatada utilizada para notificações automáticas. |
| Notification | Notificação | Mensagem automática enviada a utilizadores ou administradores sobre eventos relevantes. |
| Consent trail | Registo de consentimentos | Histórico dos consentimentos dados ou revogados pelo utilizador, com data, hora e endereço IP. |
| Export trail | Registo de exportações | Histórico das exportações de dados pessoais realizadas, com indicação do utilizador, data e IP. |
| Wipe trail | Registo de apagamentos | Histórico dos apagamentos permanentes de perfis de utilizador, com indicação do tipo de eliminação, data e IP. |
| User trail (profile change log) | Registo de alterações de perfil | Histórico das alterações realizadas ao perfil de utilizador, registadas para fins de auditoria. |
| Profile changes | Alterações ao perfil | Modificações efetuadas nos dados de um perfil de utilizador. |
| Profile deletion | Eliminação do perfil | Ação de eliminar permanentemente o perfil e os dados associados a uma conta de utilizador. |
| Lifecycle expiry | Expiração do ciclo de vida | Momento em que uma conta de utilizador excede o período de inatividade definido e fica elegível para eliminação automática. |
| Expired profile | Perfil expirado | Perfil de utilizador cujo ciclo de vida atingiu o prazo definido pela política e está pendente de eliminação. |
| Dry run | Simulação (execução a seco) | Execução de um processo sem efetuar alterações reais, para verificar o que seria realizado. Em contexto de CLI: "modo de simulação". |
| Access Key | Chave de Acesso | Credencial de identificação para a API da Amazon S3 (AWS Access Key ID). Manter maiúsculas por ser nome próprio de campo de configuração. |
| Secret Key | Chave Secreta | Credencial de autenticação para a API da Amazon S3 (AWS Secret Access Key). Manter maiúsculas por ser nome próprio de campo de configuração. |
| Bucket | Bucket | Contentor de armazenamento na Amazon S3 e serviços compatíveis. O termo inglês é universalmente adotado em contexto técnico em PT-PT; não traduzir. |
| Storage class | Classe de armazenamento | Nível de redundância e disponibilidade de um objeto armazenado na Amazon S3 (ex.: Standard, Glacier). |
| Data minimisation | Minimização dos dados | Princípio do Artigo 5.º, n.º 1, alínea c), do RGPD: os dados pessoais devem ser "adequados, pertinentes e limitados ao que é necessário". Refere-se também à eliminação automática de contas inativas. |
| Data processing | Tratamento de dados | Artigo 4.º, n.º 2, do RGPD: "qualquer operação ou conjunto de operações efetuadas sobre dados pessoais". |
| Data controller | Responsável pelo tratamento | Artigo 4.º, n.º 7, do RGPD: entidade que determina as finalidades e os meios do tratamento de dados pessoais. |
| Data subject | Titular dos dados | Artigo 4.º, n.º 1, do RGPD: pessoa singular identificada ou identificável a quem os dados dizem respeito. |
| Lifecycle deletion | Eliminação por ciclo de vida | Eliminação automática de uma conta de utilizador desencadeada pela expiração do ciclo de vida definido. |
| Lifecycle notification | Notificação de ciclo de vida | Aviso enviado ao utilizador antes da eliminação automática da sua conta por inatividade. |
