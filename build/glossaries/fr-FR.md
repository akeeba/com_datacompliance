Ce glossaire établit les traductions françaises normalisées des termes utilisés dans l'extension Akeeba Data Compliance pour Joomla. Les traductions relatives à la protection des données s'appuient sur la terminologie officielle du Règlement général sur la protection des données (RGPD) tel qu'adopté en droit français par la loi Informatique et Libertés modifiée (loi n° 78-17 du 6 janvier 1978), ainsi que sur les publications officielles de la Commission nationale de l'informatique et des libertés (CNIL). Les termes techniques propres à l'extension suivent les conventions de la communauté Joomla francophone et les meilleures pratiques de localisation des logiciels.

| English Term | French (France) Translation | Notes |
|---|---|---|
| Data Compliance | Conformité des données | Terme générique pour la conformité à la réglementation sur la protection des données. On peut aussi employer « conformité en matière de données ». |
| GDPR | RGPD | Abréviation officielle française du Règlement général sur la protection des données. Ne pas utiliser « GDPR » dans une interface en français. |
| General Data Protection Regulation | Règlement général sur la protection des données | Titre officiel en français du règlement UE 2016/679. Abréviation : RGPD. |
| Personal data | Données à caractère personnel | Terme juridique officiel défini à l'article 4(1) du RGPD. Souvent abrégé en « données personnelles » dans un contexte non juridique. |
| Personally identifiable information (PII) | Informations permettant l'identification personnelle | Terme d'origine américaine (notamment NIST) ; dans le contexte du RGPD, lui préférer « données à caractère personnel ». |
| Consent | Consentement | Terme juridique officiel du RGPD (article 4(11)). |
| Consent to data processing | Consentement au traitement des données | Formulation complète conforme à l'article 6(1)(a) du RGPD. |
| Right to be forgotten | Droit à l'effacement | Terme officiel du RGPD (article 17). Ancienne dénomination : « droit à l'oubli » ; le RGPD consacre « droit à l'effacement ». |
| Data portability right | Droit à la portabilité des données | Terme officiel du RGPD (article 20). |
| User account | Compte utilisateur | Terme standard dans les interfaces Joomla en français. |
| User profile | Profil utilisateur | Terme standard dans les interfaces Joomla en français. |
| Delete | Supprimer | Action courante de suppression (potentiellement réversible ou logique). |
| Deletion | Suppression | Nom correspondant à l'action de supprimer. |
| Wipe (permanent deletion) | Effacement (suppression définitive) | Désigne la suppression irréversible de toutes les données d'un compte. Calqué sur le « droit à l'effacement » du RGPD pour souligner le caractère définitif. |
| Export | Exporter (verbe) / Export (nom) | Le nom « export » est accepté dans le secteur informatique ; on peut aussi employer « exportation ». |
| Data export | Export de données | Exportation des données personnelles d'un utilisateur, notamment dans le cadre du droit à la portabilité. |
| Audit trail | Piste d'audit | Terme technique standard en informatique et en gestion. Parfois « journal d'audit ». |
| Audit log | Journal d'audit | Fichier ou enregistrement chronologique des actions effectuées. |
| Administrator | Administrateur | Rôle standard dans Joomla. Féminin : administratrice. |
| Super User | Super-utilisateur | Traduction conventionnelle du rôle Joomla « Super User ». |
| Account lifecycle | Cycle de vie du compte | Désigne l'ensemble des étapes de la vie d'un compte utilisateur (création, activité, expiration, suppression). |
| Lifecycle policy | Politique de cycle de vie | Règles définissant les actions automatiques appliquées selon l'état du compte (inactivité, expiration, etc.). |
| Inactive account | Compte inactif | Compte utilisateur n'ayant pas enregistré d'activité depuis une période définie. |
| Privacy Statement | Déclaration de confidentialité | Document informant les utilisateurs du traitement de leurs données. |
| Privacy Policy | Politique de confidentialité | Document contractuel ou réglementaire décrivant les pratiques en matière de protection des données personnelles. |
| Data rights | Droits sur les données | Droits des personnes concernées tels que définis par le RGPD (accès, rectification, effacement, portabilité, opposition, etc.). |
| Pseudonymise | Pseudonymiser | Technique consistant à remplacer les données directement identifiantes par des pseudonymes (article 4(5) du RGPD). |
| Anonymise | Anonymiser | Technique rendant les données irréversiblement non identifiantes. Les données anonymisées sont hors champ du RGPD. |
| Plugin | Module d'extension | Terme officiel dans la communauté Joomla France. On rencontre aussi « plugin » (anglicisme largement accepté). Dans les interfaces, préférer « plugin » si le public est technique, « module d'extension » sinon. |
| Component | Composant | Terme standard dans les interfaces Joomla en français. |
| Blocked account | Compte bloqué | Compte utilisateur dont l'accès a été suspendu ou désactivé. |
| Dashboard | Tableau de bord | Terme standard dans les interfaces Joomla en français. |
| Configuration | Configuration | Terme identique en français ; ne pas traduire. |
| Email template | Modèle d'e-mail | Gabarit utilisé pour la génération des e-mails automatisés. On écrit « e-mail » (avec trait d'union) conformément aux recommandations de l'Académie française, ou « courriel » dans un contexte plus formel. |
| Notification | Notification | Terme identique en français ; ne pas traduire. |
| Consent trail | Journal des consentements | Enregistrement chronologique des actions de consentement (accord ou retrait) d'un utilisateur. |
| Export trail | Journal des exportations | Enregistrement chronologique des demandes et opérations d'export de données. |
| Wipe trail | Journal des effacements | Enregistrement chronologique des suppressions définitives de comptes et de données. |
| User trail (profile change log) | Journal des modifications du profil | Historique des changements apportés au profil d'un utilisateur. |
| Profile changes | Modifications du profil | Changements effectués sur les informations du profil utilisateur. |
| Profile deletion | Suppression du profil | Action de supprimer définitivement le profil d'un utilisateur. |
| Lifecycle expiry | Expiration du cycle de vie | Moment à partir duquel un compte atteint l'échéance définie par la politique de cycle de vie. |
| Expired profile | Profil expiré | Profil utilisateur ayant atteint son échéance selon la politique de cycle de vie en vigueur. |
| Dry run | Simulation (mode test) | Exécution d'une opération en mode simulation, sans modification réelle des données. Terme technique courant en informatique ; « passage à blanc » est aussi utilisé. |
| Access Key (AWS S3) | Clé d'accès | Identifiant AWS utilisé pour l'authentification aux services Amazon S3. |
| Secret Key (AWS S3) | Clé secrète | Clé privée AWS associée à la clé d'accès pour l'authentification aux services Amazon S3. |
| Bucket (AWS S3 storage bucket) | Compartiment (compartiment de stockage Amazon S3) | Terme officiel AWS en français. La documentation AWS utilise « compartiment S3 » (et non « seau » ni « bucket »). |
| Storage class | Classe de stockage | Catégorie de stockage Amazon S3 définissant les caractéristiques de disponibilité, de durabilité et de coût (ex. : Standard, Glacier, etc.). |
