Questo glossario definisce le traduzioni italiane standard dei termini tecnici e legali utilizzati nell'estensione Akeeba Data Compliance per Joomla. Le traduzioni dei termini giuridici si basano sul testo ufficiale italiano del **Regolamento (UE) 2016/679** (Regolamento generale sulla protezione dei dati, comunemente noto con l'acronimo inglese GDPR), nonché sui provvedimenti del Garante per la protezione dei dati personali. I termini tecnici relativi all'interfaccia di Joomla seguono le convenzioni della localizzazione italiana ufficiale del CMS. Per i termini esclusivamente tecnici (AWS S3, infrastruttura software) si adottano le traduzioni già consolidate nella documentazione italiana di Amazon Web Services.

| English Term | Italian (Italy) Translation | Notes |
|---|---|---|
| Data Compliance | Conformità alla protezione dei dati | Locuzione usata nel contesto regolamentare italiano; in alternativa "adempimento normativo in materia di protezione dei dati". Evitare il calco "data compliance". |
| GDPR | GDPR | L'acronimo inglese è universalmente utilizzato anche in Italia; il testo ufficiale italiano del regolamento usa sia "RGPD" sia "GDPR". In contesti tecnici e di prodotto si preferisce "GDPR". |
| General Data Protection Regulation | Regolamento generale sulla protezione dei dati | Denominazione ufficiale italiana del Reg. UE 2016/679. Sigla ufficiale italiana: RGPD (usata nei testi giuridici); nell'uso comune prevale GDPR. |
| Personal data | Dati personali | Termine ufficiale dell'art. 4(1) GDPR: "qualsiasi informazione riguardante una persona fisica identificata o identificabile". |
| Personally identifiable information (PII) | Informazioni di identificazione personale (IIP) | Termine di origine anglosassone (common law / USA); nel contesto GDPR preferire "dati personali". "IIP" è accettabile in contesti tecnici quando si traduce documentazione di prodotto. |
| Consent | Consenso | Termine giuridico ufficiale: art. 4(11) GDPR. |
| Consent to data processing | Consenso al trattamento dei dati | Locuzione completa conforme all'art. 6(1)(a) e art. 7 GDPR. |
| Right to be forgotten | Diritto all'oblio | Denominazione ufficiale italiana dell'art. 17 GDPR ("Diritto alla cancellazione ('diritto all'oblio')"). |
| Right to erasure | Diritto alla cancellazione | Denominazione formale dell'art. 17 GDPR; spesso usata insieme a "diritto all'oblio". |
| Data portability right | Diritto alla portabilità dei dati | Art. 20 GDPR: "Il diritto alla portabilità dei dati". |
| User account | Account utente | Locuzione tecnica standard; "account" è termine accettato dall'Accademia della Crusca nel registro informatico. Evitare "conto utente". |
| User profile | Profilo utente | Preferibile a "account utente" quando si fa riferimento all'insieme dei dati anagrafici e delle preferenze. |
| Delete | Eliminare / Cancellare | "Eliminare" per azioni dell'interfaccia (pulsanti, menu); "cancellare" in contesti giuridici (art. 17 GDPR). Distinguere sempre dalla "cancellazione permanente" (wipe). |
| Deletion | Eliminazione / Cancellazione | Stessa distinzione della voce precedente. |
| Wipe (permanent deletion) | Cancellazione permanente / Cancellazione definitiva | Indica la rimozione irreversibile di tutti i dati personali. Nei testi giuridici: "cancellazione" (art. 17 GDPR). Nei contesti tecnici aggiungere "permanente" o "definitiva" per chiarezza. |
| Export | Esportazione | Termine tecnico standard; il verbo corrispondente è "esportare". |
| Data export | Esportazione dei dati | Locuzione tecnica standard per la funzione di portabilità. |
| Audit trail | Registro di controllo | Traduzione preferita in contesti di conformità normativa. Accettabile anche "traccia di controllo" o "audit trail" (come termine tecnico non tradotto) nei contesti esclusivamente IT. |
| Audit log | Registro di controllo / Log di controllo | "Registro di controllo" nei testi rivolti agli utenti finali; "log di controllo" o "log di audit" nei contesti tecnici. |
| Administrator | Amministratore | Traduzione standard nella localizzazione italiana di Joomla. |
| Super User | Super Utente | Traduzione usata nell'interfaccia italiana di Joomla per il ruolo con privilegi massimi. Mantenere le maiuscole per coerenza con Joomla. |
| Account lifecycle | Ciclo di vita dell'account | Locuzione tecnica; indica l'insieme delle politiche che regolano creazione, attività, inattività ed eliminazione degli account. |
| Lifecycle policy | Politica del ciclo di vita | Regola o insieme di regole che definisce i criteri di gestione automatica degli account nel tempo. |
| Inactive account | Account inattivo | Account il cui titolare non accede al sistema da un periodo di tempo superiore alla soglia configurata. |
| Privacy Statement | Informativa sulla privacy | Documento rivolto agli interessati ai sensi dell'art. 13-14 GDPR. Nota: "Privacy Policy" (vedi sotto) ha una sfumatura diversa. |
| Privacy Policy | Politica sulla privacy / Informativa sulla privacy | "Informativa sulla privacy" è il termine giuridicamente corretto ai sensi del GDPR; "politica sulla privacy" è più comune nell'uso commerciale. Usare "informativa" nei contesti legali. |
| Data rights | Diritti sulle proprie informazioni / Diritti degli interessati | "Diritti degli interessati" è la locuzione giuridica ufficiale (artt. 15-22 GDPR). "Diritti sulle proprie informazioni" è più comprensibile per l'utente finale. |
| Pseudonymise | Pseudonimizzare | Verbo ricavato dal sostantivo "pseudonimizzazione" (art. 4(5) GDPR). |
| Pseudonymisation | Pseudonimizzazione | Termine ufficiale dell'art. 4(5) GDPR: "il trattamento dei dati personali in modo tale che i dati personali non possano più essere attribuiti a un interessato specifico senza l'utilizzo di informazioni aggiuntive". |
| Anonymise | Anonimizzare | Verbo corrispondente ad "anonimizzazione". I dati anonimizzati non rientrano nell'ambito del GDPR. |
| Anonymisation | Anonimizzazione | Processo mediante il quale i dati personali vengono resi anonimi in modo irreversibile. Distinto dalla pseudonimizzazione. |
| Plugin | Plugin | Termine tecnico non tradotto, universalmente usato nella documentazione di Joomla in italiano. |
| Component | Componente | Traduzione standard nella localizzazione italiana di Joomla. |
| Blocked account | Account bloccato | Account a cui è stato negato l'accesso da un amministratore. In Joomla: stato "Bloccato". |
| Dashboard | Pannello di controllo | Traduzione preferita nell'interfaccia italiana di Joomla. In alternativa "dashboard" è accettabile come termine tecnico. |
| Configuration | Configurazione | Traduzione standard. |
| Email template | Modello di email | Traduzione standard nella localizzazione italiana di Joomla ("Mail Templates" → "Modelli di email"). |
| Notification | Notifica | Termine standard per comunicazioni automatiche inviate dal sistema. |
| Consent trail | Registro dei consensi | Traccia di controllo delle operazioni di consenso/revoca del consenso al trattamento dei dati. |
| Export trail | Registro delle esportazioni | Traccia di controllo delle richieste di esportazione dei dati personali. |
| Wipe trail | Registro delle cancellazioni | Traccia di controllo delle operazioni di cancellazione permanente dei profili utente. |
| User trail (profile change log) | Registro delle modifiche al profilo | Traccia di controllo delle modifiche apportate ai profili utente. |
| Profile changes | Modifiche al profilo | Variazioni apportate ai dati del profilo utente. |
| Profile deletion | Cancellazione del profilo | Eliminazione permanente del profilo e dei dati dell'utente. Usare "cancellazione" in coerenza con il GDPR. |
| Lifecycle expiry | Scadenza del ciclo di vita | Condizione in cui un account supera la soglia di inattività configurata e diventa candidato alla cancellazione automatica. |
| Expired profile | Profilo scaduto | Profilo utente che ha superato il periodo massimo di inattività consentito dalla politica del ciclo di vita. |
| Dry run | Simulazione | Esecuzione di un'operazione in modalità di sola verifica, senza apportare modifiche reali. In contesti tecnici da riga di comando è accettabile anche "dry run" come termine non tradotto. |
| Access Key (AWS S3) | Chiave di accesso | Traduzione usata nella documentazione italiana di Amazon Web Services per la credenziale di autenticazione alle API di S3. |
| Secret Key (AWS S3) | Chiave segreta | Traduzione usata nella documentazione italiana di Amazon Web Services per la credenziale privata abbinata alla chiave di accesso. |
| Bucket (AWS S3 storage bucket) | Bucket | Il termine "bucket" non viene tradotto nella documentazione italiana di AWS. In contesti descrittivi: "contenitore S3" o "spazio di archiviazione S3". |
| Storage class | Classe di archiviazione | Traduzione usata nella documentazione italiana di Amazon Web Services (es. "Classe di archiviazione Standard", "Classe di archiviazione Glacier"). |
| Data minimisation | Minimizzazione dei dati | Principio dell'art. 5(1)(c) GDPR: i dati personali devono essere "adeguati, pertinenti e limitati a quanto necessario". |
| Data controller | Titolare del trattamento | Art. 4(7) GDPR: soggetto che determina le finalità e i mezzi del trattamento. |
| Data processor | Responsabile del trattamento | Art. 4(8) GDPR: soggetto che tratta i dati per conto del titolare. |
| Data subject | Interessato | Art. 4(1) GDPR: persona fisica a cui si riferiscono i dati personali. |
| Legal basis (for processing) | Base giuridica (del trattamento) | Uno dei fondamenti di liceità del trattamento elencati all'art. 6 GDPR. |
| Revoke consent | Revocare il consenso | Art. 7(3) GDPR: l'interessato ha il diritto di revocare il consenso in qualsiasi momento. |
| Irreversible | Irreversibile | Aggettivo fondamentale nella descrizione della cancellazione permanente. |
| Signature method (AWS S3) | Metodo di firma | Il meccanismo crittografico usato per autenticare le richieste alle API di S3 (v2 o v4). |
| Custom endpoint | Endpoint personalizzato | URL delle API di un provider di archiviazione compatibile con S3 diverso da Amazon. |
| Virtual Hosting (S3 bucket access) | Hosting virtuale | Modalità di accesso al bucket S3 tramite URL del tipo `https://BUCKET.ENDPOINT`. |
| Path Access (S3 bucket access) | Accesso tramite percorso | Modalità legacy di accesso al bucket S3 tramite URL del tipo `https://ENDPOINT/BUCKET`. |
