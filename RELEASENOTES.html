What's new?

This release fixes an open redirect in the post-consent / post-wipe return URL handling, and closes a gap where an administrator recording consent on another user's behalf could do so without any evidence reference, which would not satisfy GDPR Article 7(1). An evidence reference (support ticket ID, email transcript, signed form, etc.) is now required and shown on the consent form. Admins with the wipe or export privilege can now also record consent for another user, matching the data subject's own consent view.

The rest of the release is hardening (stricter access checks, input validation) and low-impact bug fixes to the audit trail list views and lifecycle search.
